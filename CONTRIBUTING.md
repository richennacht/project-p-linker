# Contributing

1. Work only in the branch assigned to your area.
2. Pull the latest `integration` branch before starting a task.
3. Keep each change small enough to review in one sitting.
4. Open a pull request into `integration`.
5. Record the input, output, test and provenance impact in the pull request.
6. Do not change shared schemas without approval from all four team members.
7. Never commit passwords, access tokens, unpublished large datasets or cloud credentials.

## Completion rule

A change is complete only when it builds, passes automated checks, documents its evidence and is reviewed by another team member.
